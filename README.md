# استقبال واتساب الذكي لمكتب المحاماة

خدمة تربط رقم واتساب بـ Claude. يحاور Claude العميل ليفهم مسألته ويجمع المعلومات، حتى تكتمل أو يبلغ الحد الأقصى (10 ردود). بعدها يُرسل **ملخص الحالة مع نص المحادثة والمرفقات إلى بريد المحامي**. ثم تأتي **مهمة مجدولة** في Claude Code تقرأ الحالات الجديدة من البريد، وتُعدّ لكل حالة مذكرة دراسة أولية وترسلها في نفس سلسلة البريد.

```
العميل ⇄ واتساب ⇄ هذه الخدمة ⇄ Claude (الاستقبال)
                         │
                         └─► بريد المحامي: الملخص + المحادثة + المرفقات
                                    │
                    المهمة المجدولة ┘─► مذكرة دراسة أولية (رد في نفس السلسلة)
```

## ⚠️ تنبيهات قبل التشغيل
- **الربط غير رسمي** (مكتبة Baileys بطريقة واتساب ويب). هذا مخالف لشروط واتساب، وقد يُحظر الرقم.
  - استخدم **رقمًا مخصصًا لهذا الغرض**، لا رقمك الشخصي ولا رقم المكتب المعروف.
- **السرية**: المحادثات تُحفظ على الخادم في مجلد `data/` وتمر عبر Anthropic وGmail. أمّن الخادم، ولا ترفع مجلدي `data/` و`auth/` إلى أي مكان (هما مستبعدان في `.gitignore`).
- البوت **لا يعطي رأيًا قانونيًا ولا يذكر أتعابًا**. يجمع المعلومات فقط ويحيلها إليك.

## المتطلبات
1. **خادم يعمل على مدار الساعة**: جهاز VPS بنظام Linux (أرخص خطة تكفي)، أو جهاز في المكتب لا يُطفأ.
2. **Node.js الإصدار 20 أو أحدث**.
3. **رقم واتساب مستقل** على جوال (يكفي أن يُفتح مرة لمسح الرمز).
4. **مفتاح Anthropic API** من console.anthropic.com.
5. **حساب Gmail مرسِل** مع «كلمة مرور التطبيقات» (App Password):
   - فعّل التحقق بخطوتين في حساب Google.
   - افتح myaccount.google.com/apppasswords وأنشئ كلمة مرور للتطبيق.

## التشغيل
```bash
git clone <رابط المستودع> safat && cd safat
npm install
cp .env.example .env
nano .env        # املأ المفتاح والبريد وبيانات المكتب
npm start
```
- يظهر **رمز QR** في الشاشة.
- من جوال الرقم المخصص افتح واتساب ← الإعدادات ← الأجهزة المرتبطة ← ربط جهاز، وامسح الرمز.
- تظهر بعدها رسالة «✅ متصل بواتساب».

### إبقاؤه يعمل دائمًا (بعد إعادة تشغيل الخادم أيضًا)
```bash
sudo npm install -g pm2
pm2 start src/index.js --name whatsapp-intake
pm2 save && pm2 startup
pm2 logs whatsapp-intake      # لمتابعة السجل
```

## الإعدادات (ملف `.env`)
| المتغير | المعنى |
|---|---|
| `MAX_REPLIES` | أقصى عدد ردود قبل التحويل للمحامي (الافتراضي 10) |
| `DEBOUNCE_SECONDS` | مهلة جمع رسائل العميل المتتابعة قبل الرد (الافتراضي 8 ثوانٍ) |
| `NEW_INTAKE_AFTER_DAYS` | بعد كم يوم من التحويل يُفتح استقبال جديد إن راسل العميل مجددًا |
| `IGNORE_NUMBERS` | أرقام لا يرد عليها البوت (رقمك الشخصي مثلًا) |
| `OFFICE_NAME` / `LAWYER_NAME` / `OFFICE_INFO` | بيانات المكتب التي يعرفها البوت |
| `CLAUDE_MODEL` | النموذج (الافتراضي `claude-opus-5-5`) |

## كيف يعمل الحوار
- يجمع البوت رسائل العميل المتتابعة ويرد عليها ردًا واحدًا.
- يسأل بالتدريج عن: الاسم، ونوع المسألة، والوقائع والتواريخ، والقضية المنظورة، والمواعيد القريبة، والطلب، والمستندات.
- يقرأ **الصور وملفات PDF**. أما الرسائل الصوتية فلا يفهمها، ويُذكر في الملخص أن العميل أرسل صوتًا.
- ينهي الاستقبال في إحدى الحالات التالية:
  - اكتمال المعلومات.
  - طلب العميل التحدث مع المحامي.
  - استعجال المسألة.
  - بلوغ الحد الأقصى للردود.
- عند الإنهاء يرسل الملخص إلى البريد بعنوان يبدأ بـ `[استقبال واتساب]`. لا تغيّر هذه البادئة، فالمهمة المجدولة تبحث بها.
- إن راسل العميل بعد التحويل:
  - يرد البوت بإشعار قصير (مرة كل 12 ساعة كحد أقصى).
  - تُحفظ رسائله الجديدة في ملف محادثته (`lateMessages`)، ولا يُرسل عنها بريد جديد.
